Menu Principal
A tela inicial do Helpdesk — por onde tudo começa
🎧
Coleta de Dados Verde
Ponto de entrada recomendado para todo atendimento. Aqui você preenche o nome e contato do cliente antes de escolher o módulo. Os dados preenchidos são carregados automaticamente no módulo que você abrir.
🔗
Guia de Ativações
Abre o portal de SVAs do Grupo CedNet em uma nova aba. Use quando o cliente ligar para ativar algum serviço adicional (CedNet Play, CedNet Plus, etc.).
🌙
Botão de Tema (canto superior direito)
Alterna entre o modo claro e o modo escuro. A preferência é salva automaticamente — na próxima vez que abrir o sistema, ele vai lembrar qual tema você usou.
📋
Painel Lateral (Sidebar)
Fica do lado direito da tela em todos os módulos
▶
Como abrir e fechar
O painel começa fechado. Para abrir, clique em um dos ícones de aba no lado direito da tela. Para fechar, clique no botão ▶ dentro do painel.
📋
Aba Histórico
Guarda automaticamente tudo que você copiou durante o atendimento (coletas, agendamentos, descrições). Cada registro aparece como um card com o nome do módulo e um botão para copiar novamente ou excluir. O histórico é salvo no navegador — não some se você trocar de aba.
💡 O botão Limpar tudo apaga todos os registros do histórico de uma vez. Use com cuidado.
📝
Aba Bloco de Notas
Um campo de texto livre para anotações rápidas durante o atendimento. Use para guardar informações temporárias que não precisam ir para o histórico. O botão Copiar copia tudo que está escrito. O botão Limpar apaga o conteúdo.
💬
Aba Templates Só no Menu
Disponível apenas na tela inicial. Contém textos prontos para situações comuns: Mudança de Endereço Completa, Reboot, Patch Cord Service, Patch Cord Bridge e Patch Cord Rádio. Clique no botão do template para copiar o texto direto para a área de transferência.
🎧
Coleta de Dados
Tela de entrada recomendada para todo atendimento
📌
Para que serve?
Permite preencher o nome e contato do cliente uma única vez. Ao clicar em um módulo (Sem Conexão, Conexão Lenta, etc.), esses dados são carregados automaticamente nos campos do módulo escolhido — sem precisar digitar de novo.
📡
Via de Contato
Selecione Central se o cliente ligou pela central telefônica, ou OPA! Suite se o contato veio pelo chat/sistema OPA.
📞
Campo Contato
O campo aplica máscara automática de telefone. Funciona tanto para celular (11 dígitos) quanto para fixo (10 dígitos). Se colar um número com DDI +55, ele remove automaticamente.
📡
Sem Conexão
Para clientes sem internet — Fibra ou Rádio
1️⃣
Fluxo geral
1
Preencha a Coleta de Dados (via, nome, contato) e clique em 📋 Copiar Coleta.
2
Selecione o tipo de conexão: Fibra ou Rádio. O card correspondente aparece automaticamente.
3
Preencha os campos do diagnóstico conforme o que você verificar no sistema.
4
Se precisar agendar visita técnica, selecione Sim em "Necessário Agendamento?" e preencha o card de agendamento.
5
Copie cada bloco com o botão 📋 Copiar correspondente.
📦
CAIXA (Fibra)
Refere-se à CTO (Caixa de Terminação Óptica) — o equipamento externo na rua que distribui o sinal de fibra para os clientes. ONLINE = caixa funcionando. OFFLINE = caixa sem sinal, pode ser problema coletivo.
🔴
LOS (Fibra)
Loss of Signal — indica que o equipamento do cliente (ONU) perdeu o sinal óptico. Geralmente causado por fibra dobrada, suja ou rompida. Se o cliente responder que há uma luz vermelha piscando no equipamento, é LOS.
🔗
Botões JIRA e Zabbix (Fibra — CAIXA OFFLINE)
Ver Chamados abre o JIRA para verificar se já existe um chamado aberto para aquela região. Zabbix abre o painel de monitoramento de rede. Se já houver chamado, cole o link e copie. Se não houver, clique em "Abrir Chamado" para criar um novo.
🔍
Botão Thermix (Fibra — CAIXA ONLINE)
Abre o sistema Thermix, onde você consulta o status da ONU do cliente (sinal óptico, status PPPoE, etc.) para preencher os campos de diagnóstico.
📡
BASE (Rádio)
A estação base é a antena da CedNet que transmite o sinal para o rádio do cliente. Se a BASE estiver OFFLINE, o problema é coletivo — verifique o JIRA. Se estiver ONLINE, o problema pode ser no rádio do cliente.
🔍
Botões AirControl e Grafana (Rádio)
AirControl é o sistema de gerenciamento dos rádios — consulte o status do equipamento do cliente. Grafana exibe gráficos de tráfego e qualidade de sinal da rede.
📋
Botão 📋 pequeno (Coleta de Informações)
Aparece no card de agendamento ao lado do título "Coleta de Informações". Copia de uma vez só todos os dados técnicos preenchidos (PPPoE, OLT, PON, CAIXA, MAC, etc.) em formato de texto pronto para colar na OS.
➕
Botão + Adicionar Contato
Permite incluir mais de um número de contato no agendamento. Cada contato adicionado ganha um botão ✕ para remover se necessário.
📶
TR069
Protocolo de gerenciamento remoto do roteador do cliente. Selecione Ativar se o técnico precisará ativar o TR069 durante a visita. Selecione Sem Necessidade se já estiver ativo ou não for aplicável.
🐢
Conexão Lenta
Para clientes com instabilidade ou lentidão
🔁
Reincidência
Indica se o cliente já entrou em contato antes com o mesmo problema. Selecione Sim se for um problema que já ocorreu anteriormente. Essa informação vai para o texto copiado da coleta.
✅
Conexão Normalizou?
Após o diagnóstico e as tentativas de resolução remota, selecione Sim se o problema foi resolvido (aparece o botão "Copiar Resolução") ou Não se precisar agendar visita técnica (aparece o card de agendamento).
⚠️ Atenção: neste módulo a lógica é invertida — "Não" abre o agendamento e "Sim" abre a resolução.
📦
Mudança de Endereço
Coleta completa para transferência de instalação
🏙️
Área Urbana x Rural
Se o cliente for se mudar para área Rural, o sistema exibe um aviso para transferir o atendimento ao setor Comercial Rural — Viabilidade. Se for Urbana, o formulário completo de coleta é exibido.
📮
Auto-fill de CEP
Ao digitar o CEP do novo endereço e sair do campo, o sistema consulta automaticamente a API ViaCEP e preenche os campos de Estado, Cidade, Bairro e Rua. Você só precisa digitar o número da casa.
💰
Taxa
Indica se o cliente paga ou não pela mudança. Isento = sem cobrança. Não Isento = há cobrança de taxa. Essa informação é incluída no texto copiado.
📦
Equipamentos
Pergunta se o cliente vai levar os equipamentos (ONU/roteador) para o novo endereço ou se vai deixar para a equipe técnica buscar.
🏠
Telhado
Tipo de telhado do novo endereço. Importante para a equipe técnica saber o material antes da visita de instalação. Se selecionar Outro, aparece um campo para digitar o tipo.
🧰
Serviços — Mudança de Cômodo / Passagem de Cabo
Agendamento de serviços internos pagos
🚪
Mudança de Cômodo
O cliente quer mudar o ponto de internet de um cômodo para outro dentro da mesma casa. O card exibe os valores e prazos automaticamente. Você só precisa preencher a disponibilidade, observações e PPPoE.
🔌
Passagem de Cabo
O cliente quer que a equipe técnica passe um cabo de rede em algum ponto da casa. Mesmo fluxo da mudança de cômodo — valores, disponibilidade e PPPoE.
📋
Botão 📋 Copiar (no card de valores)
Copia apenas o bloco de template com os valores e prazos — útil para enviar ao cliente via chat sem precisar preencher o formulário completo.
🛠️
Suporte de SVA's
Serviços de Valor Agregado — streaming, TV, etc.
🔑
Acessos (CedNet Play e CedNet Plus)
Exibe as credenciais padrão de acesso para cada plataforma. O botão 📋 Copiar ao lado de cada plataforma copia o texto de login e senha formatado para enviar ao cliente.
📺
GloboPlay, Setup BOX, CedNet Play, Premiere, Outro SVA
Cada opção exibe um formulário com os problemas mais comuns daquele serviço. Selecione o problema relatado pelo cliente, adicione uma observação se necessário e clique em 📋 Copiar Atendimento.
💲
Financeiro
Comprovante de pagamento e 2ª via de boleto
🧾
Comprovante de Pagamento
Use quando o cliente enviar um comprovante de pagamento. Preencha a forma de pagamento (PIX ou Boleto), se o pagamento consta no sistema e se o comprovante foi anexado na OS. O texto copiado registra tudo isso.
📄
2ª Via de Boleto
Use quando o cliente solicitar uma segunda via para pagamento. Selecione a forma (PIX, Boleto ou Ambos) e copie o registro. A 2ª via em si é gerada no sistema financeiro — este módulo apenas registra o atendimento.
❓
Dúvidas
Para atendimentos que não se encaixam nos outros módulos
📂
Tipos de dúvida
Suporte — dúvidas técnicas gerais.
Financeiro — dúvidas sobre faturas, cobranças, etc.
Comercial — dúvidas sobre planos, upgrades, etc.
Previsão — cliente perguntando quando a visita técnica vai acontecer.
📞
Retornar Contato
Se o cliente quiser que a CedNet retorne o contato, selecione Sim. Aparece um card para preencher o protocolo e a disponibilidade do cliente para receber a ligação.
